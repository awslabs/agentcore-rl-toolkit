## Before vs After

<Tabs>
  <TabItem label="Before">

A math agent that uses [Bedrock AgentCore Runtime](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/agents-tools-runtime.html) and the [Strands Agents](https://strandsagents.com/) framework.


```python
from bedrock_agentcore.runtime import BedrockAgentCoreApp
from strands import Agent
from strands.models import BedrockModel
from strands_tools import calculator

app = BedrockAgentCoreApp()


@app.entrypoint
def invoke_agent(payload):
    model = BedrockModel(model_id="us.anthropic.claude-sonnet-5-5")
    agent = Agent(
        model=model,
        tools=[calculator],
        system_prompt="Solve the math problem step by step.",
    )

    user_input = payload.get("prompt")
    response = agent(user_input)
    # Skip the leading reasoningContent block from adaptive thinking.
    content = response.message.get("content") or []
    return "".join(block["text"] for block in content if "text" in block)


if __name__ == "__main__":
    app.run()
```

  </TabItem>
  <TabItem label="After — adapted for RL">

The tools, system prompt, and agent logic stay the same.


```python
from agentcore_rl_toolkit import AgentCoreRuntimeApp
from strands import Agent
from strands.models.openai import OpenAIModel
from strands_tools import calculator
from reward import MyReward

app = AgentCoreRuntimeApp()
reward_fn = MyReward()


@app.entrypoint
def invoke_agent(payload: dict):
    # Configure the model endpoint at runtime via the invocation payload.
    cfg = payload["_config"]
    model = OpenAIModel(
        client_args={"api_key": cfg.get("api_key") or "EMPTY", "base_url": cfg["base_url"]},
        model_id=cfg["model_id"],
        params=cfg.get("sampling_params", {}),
    )
    agent = Agent(
        model=model,
        tools=[calculator],
        system_prompt="Solve the math problem step by step.",
    )

    response = agent(payload["prompt"])

    # Compute a scalar reward.
    content = response.message.get("content") or []
    reward = reward_fn(
        response_text="".join(block["text"] for block in content if "text" in block),
        ground_truth=payload["answer"],
    )
    return {"reward": float(reward)}


if __name__ == "__main__":
    app.run()
```

## Deploy to AgentCore Runtime

The container must implement the Runtime's
[HTTP contract](https://docs.aws.amazon.com/bedrock-agentcore/latest/devguide/runtime-http-protocol-contract.html):
serve `/invocations` and `/ping` on port 8080. `AgentCoreRuntimeApp` provides
these endpoints. The examples use ARM64 images built through the
[AgentCore CLI](https://github.com/aws/agentcore-cli) and CodeBuild.

The Runtime must be able to reach the inference server or rollout gateway.
For a private endpoint, deploy into a VPC that routes to it and allows traffic
on its TCP port. Container builds also need access to dependency sources.

Each example README includes its deployment commands. For CLI setup, IAM, and
configuration options, see the official
[CLI documentation](https://github.com/aws/agentcore-cli#readme),
[IAM guide](https://github.com/aws/agentcore-cli/blob/main/docs/PERMISSIONS.md), and
[configuration reference](https://github.com/aws/agentcore-cli/blob/main/docs/configuration.md).

A successful deploy prints the **agent runtime ARN** — that's the
identifier the training backend uses to invoke the agent. For verl and slime,
configure the HTTP session backend:

```yaml
rollout_session_backend:
  backend: agentcore_rl_toolkit.rollout_session.agentcore_http_session.AgentCoreHttpSession
  agentcore_runtime_arn: "arn:aws:bedrock-agentcore:REGION:ACCOUNT:runtime/AGENT_ID"
```
