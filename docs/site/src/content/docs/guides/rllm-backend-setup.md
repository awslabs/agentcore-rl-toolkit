rLLM natively integrates with AWS Bedrock AgentCore Runtime.
Installation, configuration, training, and troubleshooting instructions are
maintained in the [rLLM AgentCore documentation](https://docs.rllm-project.com/agent-runtimes/agentcore).

If you previously installed rLLM through this repository's `.[rllm]` extra,
follow the upstream installation instructions instead; that extra has been removed.

Use ART's [agent adaptation and deployment guide](/agentcore-rl-toolkit/guides/agent-adaptation/)
to prepare your agent, or browse the toolkit's
[Training Backends](/agentcore-rl-toolkit/guides/overview/#training-backends).
